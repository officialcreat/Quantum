# Contributing to Quantum

Thank you for your interest in contributing to Quantum (QTM).

## Development Principles

- Write clean and documented C++ code.
- Keep commits small and meaningful.
- Maintain compatibility with Quantum Mainnet.
- Follow the MIT License.

## Pull Requests

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes.
4. Submit a Pull Request.

## Bug Reports

Please include:

- Operating system
- Wallet version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Security

Do not publish security vulnerabilities publicly.

Report them to:

officialqtm@proton.me
