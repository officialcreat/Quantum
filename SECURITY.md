# Quantum Security Policy

## Supported Version

| Version | Supported |
|----------|-----------|
| Mainnet 1.0 | ✅ |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Quantum, please report it privately.

Email: officialqtm@proton.me

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Proof of concept (if available)

---

## Responsible Disclosure

We ask security researchers to avoid public disclosure until the issue has been investigated and resolved.

---

## Scope

This policy applies to:

- Quantum Core
- Wallet
- Explorer
- API
- Mainnet Network
